welcome — a few permissions

So everything works from the first minute, your browser will ask for a few permissions. Nothing is sent to any server.

  • microphone — to record voice messages. It also lets your browser reveal its real IPv6 address, which is required to connect
  • camera — only to scan QR codes
  • clipboard — pasting codes (where the browser supports it)
  • sound — message notifications
  • persistent storage — keeps your identity key from being cleared

private chat room

Direct WebRTC connection — no chat server. Signaling (codes) is exchanged manually between participants.

Requirement: this app works over IPv6 only. Both devices need an IPv6 address — a public one to connect across the internet, or a private one (starting with fd) on the same network. No STUN/TURN servers are used.

Host setup
Share the invite code. Each participant creates a separate reply code. Paste each reply code below and send its generated confirmation code back.

If you set a password, peers must know it. The password is never placed in the invite code.

Peer setup
Paste the invite code. If the room is password protected, enter the same password.

Send the reply code to the Host. The Host will return a confirmation code.
