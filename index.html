ABOUT
A serverless, IRC-style chat client. Peers connect directly over WebRTC — STUN/TURN servers (optional, set by you) only help find a path and never see readable messages. Works on a LAN or IPv6 with no servers at all; across different networks you may need a STUN or TURN server reachable from both sides (e.g. one inside your intranet). Signaling is done manually by exchanging codes.

private chat room

Direct WebRTC connection — no chat server. Signaling (codes) is exchanged manually between participants.

Requirement: to connect two devices on different networks, the network each of you is on must have IPv6 enabled (a public IPv6 address). On the same Wi‑Fi / LAN nothing special is needed. Public STUN servers are used by default to help IPv4 links; “intranet mode” turns them off for internet outages.

NETWORK (ICE)

Servers, comma-separated. STUN: stun:host:3478   TURN: turn:host:3478|username|password. Both sides should use servers they can reach. Without internet, Google STUN is unreachable — enable intranet mode and add your internal servers (without any server, only same-LAN / IPv6 connections can work).
